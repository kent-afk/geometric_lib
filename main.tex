\textit{Код calculate.py:}
\begin{lstlisting}
import circle
import square

figs = ['circle', 'square'] 
funcs = ['perimeter', 'area'] 
sizes = {} 

def calc(fig, func, size): 
	assert fig in figs 
	assert func in funcs

	result = eval(f'{fig}.{func}(*{size})') 
	print(f'{func}of{fig}is{result}') 

if __name__ == "__main__":
	func = ''
	fig = ''
	size = list()
    
	while fig not in figs:
		fig = input(f"Enter figure name, avaliable are {figs}:\n")
	
	while func not in funcs:
		func = input(f"Enter function name, avaliable are {funcs}:\n")
	
	while len(size) != sizes.get(f"{func}-{fig}", 1):
		size = list(map(int, input("Input figure sizes separated by space, 1 for circle and square\n").split(' ')))
	
	calc(fig, func, size)
\end{lstlisting}
\\
Данная функция позволяет считать по вводимым данным площадь и периметр всех доступных фигур

\section*{Работа с circle.py }

\textit{Код circle.py:}
\begin{lstlisting}
import math

def area(r):
    return math.pi * r * r

def perimeter(r):
    return 2 * math.pi * r


\end{lstlisting}

Данная программа принимает значение радиуса и в зависимости от операции использует определенную формулу. 
Для площади: $\pi r^2$ , а для периметра: $2\pi r$.

\section*{Работа с square.py}
\textit{Код square.py:}
\begin{lstlisting}
def area(a):
    return a * a

def perimeter(a):
    return 4 * a
\end{lstlisting}

Данная программа принимает значение стороны квадрата и может выполнять 2 операции:

- Вычисление площади: $a^2$

- Вычисление периметра: $4a$

\section*{Работа с triangle.py:}
\begin{lstlisting}
def area(a, b, c):
    return (a + b + c) / 2

def perimeter(a, b, c):
    return a + b + c
\end{lstlisting}
Данная программа принимает значение сторон треугольника и может выполнять 2 операции:

- Вычисление площади: $\frac{(a+b+c)}{2}$

- Вычисление периметра: $a+b+c$
